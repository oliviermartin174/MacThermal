# MacThermal

Outil gratuit de surveillance thermique dans la barre des menus, développé en Swift pour le Mac Pro 2019 Intel. Dépôt privé de préparation à la distribution.

- Températures CPU et Radeon, avec identification de chaque GPU.

- Seuils indépendants, alertes visuelles rouges, signal sonore et notifications.

- Renfort temporaire des quatre ventilateurs du Mac, autorisé par une demande macOS au nom de MacThermal.

- Retour explicite à la régulation automatique Apple après refroidissement ; superviseur de restauration indépendant.

Version actuelle : **1.3**. Matériel validé : MacPro7,1, Xeon W 12 cœurs, Radeon PRO W6800X et Radeon Pro 580X. La compatibilité n’est pas revendiquée pour les autres modèles. CPU : capteur de proximité, pas la température du cœur le plus chaud.
